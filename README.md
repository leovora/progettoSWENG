## Overview

**PathFinder** is a web application that allows users to **write and play interactive stories**.

An interactive story is a narrative in which the player makes decisions that influence how the story unfolds. The player is presented with a sequence of scenarios, each offering one or more choices — the chosen option determines the next scenario, leading to different branching paths and one or more possible endings.

### Key Features

- **Write stories** — create branching narratives with multiple scenarios, choices, riddles, and collectible items that unlock new paths
- **Play stories** — read scenarios, make choices (some gated by inventory items), answer riddles, and reach different endings
- **Save & resume** — pause and resume an ongoing game at any time; multiple stories can be played simultaneously
- **Browse the catalogue** — search and filter stories by author, length, and other criteria
- **User accounts** — register, log in, and manage written and played stories
